# V2 开发与验证记录

2026-11-18；规则版本 `night-market-2.0`。本页是当前交付记录，旧 `VERIFICATION.md` 的 V1 数量与截图作为历史保留。

## 已开发

- 十款武器：默认取餐夹、纸袋气炮、飞筷匣、汤灵保温壶、拆箱快刀、回旋餐盘、配送伞、签收尺剑、弹射餐盒、派单符册。独立命中、攻击动作、特效与声音；局内拾取换装、退换锁定和旧弹道完成。
- 原三技能及新增十技能，共十三种；图鉴、真实道具图标、持续状态优先级、补给三选一及组合规则。
- 玩家 100 HP、敌人差异生命与接触伤害、0.75 秒全局受击保护、实际伤害与防御反馈。
- 每怪一条生命条、最多三行伤害记录；第四击折叠旧行、独立过期、敌人全屏十二行预算，玩家伤害/回血独立预留。组间必须无重叠，无空位省略低优先组且不补播。
- 原创角色分层骨骼：站立呼吸、按实际位移走跑、前后朝向、持械、十武器上肢动作与收势、受击和倒地。停止和顶墙不会继续原地跑步。
- 配送试验场：十武器选择、十三技能触发、三类敌人、补血、清场、重置、半速/正常速度；不自然刷新、不记正式纪录。

## 验证结果

| 项目 | 结果 |
|---|---|
| Vitest 单元与集成 | 89 项通过：核心 17、武器/整合 21、技能 23、伤害布局 14、平台存档 14 |
| Chromium E2E | 原流程 7 项通过；V2 新流程 3 项通过，覆盖全部十武器/十三技能选择、十武器真实扣血、HP/补血、状态顺序、半速、暂停、旋转及练习记录隔离 |
| HTTP 服务 | 7 项通过 |
| TypeScript 与 Vite | 正式构建通过 |
| 4173 正式产物 | 加载、开始、移动、暂停、声音设置通过；无页面/资源错误；无开发调试入口 |
| 视觉检查 | 实际查看站立与跑步、武器、技能堆叠、桌面/手机横屏、图鉴、试验工具；修正道具透明底、路线偏移、假钩线、范围提示及伤害组重叠 |

本机 Chromium 正式产物早期战斗短采样约 60.3 FPS、p95 帧间隔 16.7 ms。人工构造六十敌人并叠加多个技能的 150 帧采样，中位 16.7 ms、p95 16.8 ms，采样结束剩 59 敌；拥挤场景自动降为 DPR 1。该数据不代表 Android/iOS 低端真机性能。
