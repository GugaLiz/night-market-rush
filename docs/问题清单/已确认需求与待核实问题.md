# 已确认需求与待核实问题

## V3 已实现、调整时需要回归的需求

| 用户要求 | 已有基础与复验方法 |
|---|---|
| 人物比最小食物怪大，站立、走跑和战斗动作可辨 | 当前人物约 117 逻辑单位高，小包子约 55。手机横屏依次检查站稳、起步、转向、持械挥击或发射、受击；大特效下能看见人物脚点和危险弹道 |
| 默认武器，朝前持续攻击，局内触碰武器包换装 | 默认取餐夹。试验场轮换十种近战、远程、暗器、刀剑与法术风格武器，核对范围、出手方向、停止时最后朝向、已飞出的投射物和旧武器回捡 |
| 武器与技能道具并存，能实际试玩每一种 | 十武器、十三技能已有图鉴与试验场。检查技能卡与武器包能辨认、能绕开，换装或触发技能时移动仍连续。逐款效果由试玩确认。[武器设计](../design-v2-review/02_十款武器.md) · [技能实装](../V2_SKILLS_IMPLEMENTATION.md) |
| 玩家和怪物均可见受伤反馈；武器多段命中最多五行 | 检查不同怪的接触伤害、远程命中、玩家 HP 和怪物血条。多只怪同时受击时，逐只核对真实扣血、字号由大变小、死亡后停止，兼顾文字堆叠与全屏 30 行显示预算 |
| 轻微同向加速，独立冲刺带冷却 | 当前最高加速 12%，冲刺冷却 3 秒。实测普通直行、摇杆微调、松手、键盘冲刺与触屏双指冲刺。重点观察小角度转向是否反复重置蓄速、松开冲刺手指是否干扰移动 |
| 怪多、靠近较慢、有远程威胁，玩家能主动扫怪 | 在密集场景记录怪群聚集速度、可走缺口、冲刺怪预警和慢弹轨迹；保留真实的受伤、护盾和躲避结果 |
| 暖色手绘夜市、快递员人物与真实道具；另两套设计备用 | 当前评审与开发对准夜市主玩法。原设计中的「月影图书馆」「珊瑚救援队」是后续换模式时的备选 |

当前规则与既有测试覆盖见[V3 核心说明](../V3_CORE_IMPLEMENTATION.md)和[V3 验收记录](../V3_VERIFICATION.md)。这些功能来自项目需求，引用原作时需另列录像依据。

## 原作尚待查明的问题

| 问题 | 已有线索 | 下一步取证 |
|---|---|---|
| WAVE 由什么触发，有多少波？ | B 有 WAVE 2 和 WAVE 7，局间画面连续 | 并列两段录像各次换波前的时间、怪物计数和画面事件，标出支持或反驳同一触发条件的样本 |
| 各颜色道具如何生成、对应什么技能、能否叠加？ | 场上可同时有多件；B 00:14 左右靠近粉色道具后出现橙色爆发 | 追踪可辨认的单个道具，从出现、接触到消失；技能重叠的样本单列。正式掉落频率和概率待核实 |
| 主火团与外围火团怎样命中？蓝区、成列光点归属和作用是什么？ | 可辨认其位置、数量变化和画面持续过程 | 追踪进出边缘的单体，核对移动或受击变化，遇到多技能叠加时只登记可见现象 |
| 金币的面额、掉率、吸附半径和倍增条件？ | 清怪后仍有地面金币；B 这局结算金币有「双倍」提示 | 在孤立金币处比对距离、位置和计数，每种结算倍数需有对应界面或独立样本 |
| 连击何时中断，击败、成绩、时间如何换算？ | B 这局怪物计数与成绩同为 2608，时间与金币分列 | 采样连击形成和中断的前后帧，按不同对局交叉验证。记录 V3 计分迁移时的旧纪录隔离 |
| 绿色长条表示什么，原作如何判定死亡、复活与解锁？ | 可见绿条、复活选择、任务及奖励弹窗 | 核对受击、拾取和结束前的条值与界面说明。用户已确认的项目 HP 单独验收 |
| 参考录屏采用哪些操作，声音与触摸响应能测到什么程度？ | B 有摇杆和触点，可辨片段里没有独立普攻按钮；两片为 25 fps | 观察转向与画面位移、对听声轨。要辨别精确输入延迟、其他控制设置与设备差异，需要额外的可验证样本 |

素材索引、视频时长、采样方法和关键帧见[录像分析记录](../video-review/视频分析与V4优化方案.md)。
