# V3 动态试玩与验收指南

本页针对 `night-market-3.0`，以实际网页为准。十款武器统一沿最近有效移动方向持续出手；停止后保持原方向，无目标也出招。不要用V2“等敌人靠近才攻击”的预期验收。

## 一、先看一分钟的操作

1. 正式局向一个方向移动约2.4秒：1.8秒后开始轻微提速，最高1.12倍；明显转向、松手或顶墙会重置。速度变化只影响走位，不提高伤害。
2. 沿当前方向冲刺：持续约0.18秒、2.5倍基础速度、冷却3秒。在敌人或慢弹穿越期间不掉血，气泡也不应白白消耗；冲刺结束后仍重叠会恢复正常受伤。冲刺不能越界。
3. 首武器包约4秒出现，位于玩家附近安全区；之后约10–14秒补一次，最多两自然包。触碰即换，退换包2秒锁定，需离开再进入，10秒到期。
4. 注意玩家脚点和武器方向，尝试横向掠过敌群、转身清理，不把向怪物直冲当作唯一攻击方式。

## 二、逐款武器与真实伤害

在配送试验场选择武器，分别观察空场持续攻击、正面单怪、身后单怪、前方密群、边移动边攻击、转向后下一次出手。尺剑与餐盒仍有明显前摇或延迟；餐盘去回分开；符纸先飞行命中，再跳链；汤灵不会从背后跨场锁敌。

给耐打目标一次攻击，核对总血条与最多五段数字之和。每段都是实际扣血事件，不是一次扣血复制五个数字。目标剩9点而被刀命中时，只能扣9并结束，后续段不再触发；同刻多个来源不能重复计击败。技能电扇与滑板保留自己的单次/节拍规则。

试验场无计分且不会覆盖正式成绩。补血只恢复生命，不复活已结束的试验；用重置重新开始。

## 三、危险与防护组合

- 包子群缓慢聚拢，远处有分散游走，近身有软分离。观察是否留有绕行空间，群体不应全叠成同一点。
- 盒怪同一时刻最多一只预警/冲刺，1.1秒预警、0.5秒较慢冲刺；留意方向锁定后侧移的收益。
- 正式局30秒后开始出现碗怪；碗怪射击前0.9秒锁定方向，随后慢弹以90单位/秒前进，每弹8伤害。预警期间横移应能躲开，最多12颗敌弹。
- 伞只在正面亮起窗口挡一次，不能靠收伞动画免疫侧后；需分别测试正面敌弹、侧后敌弹、实体与敌弹同刻到达。全局保护或冲刺期间不消耗有效防御。
- 气泡抵消一次完整伤害并给0.75秒保护；同刻多弹不能连穿多次，受保护期间的新弹接触后消失。
- 手铃可取消尚未发射的碗怪预警，已射出的慢弹继续飞行。

## 四、补给与换装组合

在已有3件道具时触发补给券，投递中的物件提前计入4个有效槽位。选择一件后，其余同组立即失去拾取资格，仅保留短回收视觉。连用取餐钩不能拿第二件，也不能吸武器包。两个自然武器包不能重叠，退换仍遵循冷却和离圈规则。

## 五、性能检查和已测观察

2026-11-18 本机纯模拟测试：600秒自然刷怪、默认武器、固定位置、玩家无敌，36,000步耗时约7.4秒，平均0.206毫秒/步，观察最大单步3.75毫秒；实际达到100怪与12敌弹上限，结束时无越界NaN或重复击杀。这个样本测逻辑CPU，不包含画布、音频、手机GPU，也不代表手机帧率。另有24玩家投射物硬上限测试。

三颗正常种子15/55/810，站桩脚本生存22.5–23.9秒；固定绕行脚本46.9–50.0秒。脚本没有主动规划冲刺或取道具，不能当难度最终结论。它说明站桩不构成永久安全，移动有收益。真人试玩应重点记录：首次碰伤时间、第一次主动换装时间、30秒前能否读清方向、远程弹是否看得见、冲刺能否稳定救场。

推荐每台目标设备跑3局各2分钟，再进入试验场制造密群/餐盘/符链/补给叠加。记录设备、浏览器、屏幕、画质、是否发热和卡顿位置；网页通过后仍需Android/iOS及微信小游戏的各自适配和真机验证。

## 六、审查结论与边界

已检查五段实际扣血、低HP提前结束、多来源重复击败、冲刺与敌弹同刻排序、慢群实际聚拢、补给有效槽位和十分钟预算。自然武器包安全位置已补充避开已有武器包。伞挡敌弹与冲刺期间不耗格挡已由武器模块修复，并通过实际Game组合回归：正面两弹只挡一弹、另一弹正常扣8；冲刺穿弹不耗伞或气泡。该次武器与审查测试31项全部通过。
