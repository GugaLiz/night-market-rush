# 两段参考视频分析与 V4 优化方案

日期：2026-11-18。状态：分析与候选设计，尚未实施；本轮未修改游戏源码、构建产物或部署。

## 一、结论

两段视频最值得借鉴的体验是：**移动选择路线 → 引出或绕开怪群 → 拿到关键技能 → 大范围、持续数秒地清扫 → 怪物转化为奖励 → 沿清出的空地收取并寻找下一张技能 → 换波。**

当前《夜市急送》已有持续方向攻击、十武器、十三技能、HP、冲刺和五行伤害，但主要仍是“连续普攻＋随机道具＋怪物缓慢围追”。缺口不在功能数量，而在技能是否值得抢、刷怪是否提供可读路线、清场后是否有收获和阶段变化。

建议定位为 **武器负责开路，技能负责改变战局，走位负责串起清扫和奖励**。保留用户已经认可的外卖快递员主题、人物道具风格、默认武器与换装、HP、方向攻击、微加速、冲刺和五行爆字。五行爆字是本项目的增强设计，不冒称来自参考视频。

## 五、建议的 V4 核心玩法

### 1. 保留双层攻击，先强化三种代表技能

先保持十款武器的方向感、手持动作和差异，不立即全面削弱普攻。用更强的技能空间覆盖和持续效果，验证玩家是否愿意主动抢卡。后续若普攻独自解决绝大部分威胁，再微调目标上限与冷却，而不是让小怪突然变成血厚沙包。

| 技能 | 建议改造 | 候选起点，待试玩 |
|---|---|---|
| 旋风电扇 | 立即打出周身清扫冲击，随后风压扩散；清掉小怪、推开幸存的大怪，形成可走空地 | 起势约0.1秒，0.3–0.5秒扩散至半径220左右；主伤害结算有明确次数，视觉余风约1.5秒不额外偷加伤害 |
| 滑板环绕 | 拾取后进入短暂移动清扫窗口，玩家主动切入怪群收益更高 | 约4秒，外圈候选110–125；内圈和图像位置与伤害环一致，按真实合法接触/间隔伤害，不每帧重复 |
| 汽水缓速 | 从一次减速改为约4秒的地面区域；敌人经过时受控，便于玩家绕行、引怪和用主武器处理 | 半径180–210；首轮先做清楚的区域控制，冰冻破裂或额外伤害作为后续组合，不同时堆所有能力 |
| 气泡缓冲 | 保留一次完整防护，承担路线判断失误的容错 | 继续有明确到期/消耗反馈，不与冲刺叠成长期免伤 |

目标体验：在设计好的中等密度测试群中，一张主力清扫卡可在约2–3秒内清掉一片可感知区域，例如十余只小怪，同时保留大怪或另一方向的后续处理任务。这个结果是验收目标，不是给每张卡写死最低击杀数，也不通过隐性补杀兑现。

开局掉落池先集中于电扇、滑板、汽水、气泡。其他九种技能保持可用并保留在试验场，后续波次按作用加入，避免新手连续拿到得分卡、加速卡、停刷卡，却没体验到主力清扫。

### 2. 把怪物刷新设计成“可选择的路线”

保留百怪上限和慢速基调，先不继续加数量。建立几种可复用的组合：

- **扫街小队：**小怪成疏松队列从一到两个方向进入，留出可穿行缝隙。
- **街区散群：**一部分小怪在局部缓慢游走，玩家可以主动去打扫，避免所有怪必然汇成同一团。
- **追逐组：**只让部分敌人稳定追踪，制造引怪和换边的价值。
- **拦路组：**少量厚血怪形成清扫顺序；玩家可绕过后拿强技能处理，不靠全体加速制造难度。
- **特殊组：**箱怪冲刺与碗怪慢弹穿插；保留同时最多一冲刺、两远程预警，关键取卡路径不同时被多个不可避攻击封死。

初期候选结构是约六成小型可清扫怪、三成追逐/拦路单位、一成特殊威胁；具体比例按波次配置，不称作视频原始比例。刷怪时检查玩家附近、预计冲刺终点和主要移动通道，不在贴脸位置突然生成。

每波约30–40秒可以作为第一轮试验起点：建立散群 → 局部加压 → 提供强技能机会 → 清扫 → 留2–3秒收获窗口。**节奏阶段不代替玩家击杀**：时间到不能直接抹掉所有剩余敌人冒充玩家成果；收尾残留应少量可清，或用明确的波末奖励效果处理并单独记账。

### 3. 建立击杀奖励与下一次技能的联系

新增主题化的“配送积分/小费”掉落，先只用于局内成绩和局后累计。击杀后在原位置短散开，接近后吸附，清场后的空地因此成为有价值的路线。

- 击杀分与拾取奖励分分别定义，避免一份奖励重复记账；存活分占比可降低，但先采集数据再定最终值。
- 同处大量奖励合并为更高面额的一个实体，显示与数值分离；奖励不能挡移动、弹道或预警。
- 奖励收取半径候选60–80逻辑单位，不要求精准逐个踩点；不直接把全场奖励瞬间吸空，否则失去收获路线。
- 由受控掉落规则保证后续取卡机会，例如累计清扫达到一个小目标后放出下一张主力卡，同时保留短时间无卡的兜底。
- 不能只靠击杀供卡：低熟练度玩家需要可达的保底卡，避免“打不过→没技能→更打不过”。也不能每次击杀都生成卡，造成无限清场循环。
- 波次切换保留或明确自动结算剩余奖励，不悄悄删除。技能卡不被奖励吸附规则自动拿走，继续保留选择路线的意义。

武器包继续触碰换装、旧武器退换；用独立颜色、光柱和轮廓区分技能卡。生成位置尽量避开关键技能的必经路线，降低顺路取卡时误换武器的概率，不增加打断游玩的确认弹窗。

### 4. 保留五段爆字，但按武器形成打击节奏

用户希望的“周边多只怪同时爆五行”保留。需要区分 **真实命中、视觉显示、声音播放**，避免三者都机械重复五次。

| 武器表现类型 | 建议节奏 |
|---|---|
| 取餐夹、飞筷 | 短促连续，五段可在约0.12–0.22秒内完成；每段要有合法判定，离开范围不继续扣血 |
| 尺剑 | 明显蓄势、一次强冲击，五个实际子伤害集中在短窗口；同次打击只给一个主要重击音和受击姿态 |
| 餐盘 | 去程与回程是两次可辨认接触，各自形成记录；不能把未发生的回程伤害提前展示 |
| 餐盒 | 落点预告、落地爆发、周围多目标同步受伤；大范围击败与掉落是主反馈 |
| 汤灵、符册 | 命中与跳转的节奏可见，后续目标真正被接触才出现记录 |

保留伤害总量守恒和低血量提前死亡。近身重要目标可完整显示五行，远处主要通过击败动作和奖励爆出表现；全屏三十行预算继续保留。字号由大到小的变化应短促清晰，避免把五个数字做成高耸的常驻表格。

效果分为起势、命中峰值、余波、消退。友方大特效可以有强边缘与半透明中心，但人物轮廓、敌弹和危险边界必须优先可见。声音建议使用一次主要命中音加少量细碎声、击败反馈和奖励收取音，保持并发限制；此为新设计建议，不是从录像测得的混音参数。

### 5. 操作要服务于穿缝抢卡

保留方向攻击和独立冲刺，不因为参考录像没有冲刺按钮而删除已经确认的功能。

- 优先保持当前快速起停，不能为了所谓惯性让人物明显打滑。
- 微加速允许小角度连续修正；候选改为小转弯保留部分积累、大转向渐退、停止快速归零，避免约10°偏转就反复失速。
- 冲刺先保持当前3秒冷却，用真实测试判断它是否帮助穿过危险缺口，而非成为可以无脑反复用的常驻免伤。
- 释放技能不锁移动，工具按钮不抢摇杆，暂停/旋转后不遗留输入。
- 人物保持大于小怪，不继续单纯增大人物和特效；用轮廓、脚点、危险配色增加可读性。检查顶部安全区和手机长屏利用率，避免放大人物后持续挤压走位空间。

## 六、其余技能与后续内容

先用现有十三技能完成分工，不再一次性增加十几张新卡。

| 技能组 | 后续分工 |
|---|---|
| 诱饵、路锥 | 聚怪与造路线；先把聚集/阻挡的位置和有效时间做清楚 |
| 手铃 | 打断当前威胁，保留短救场作用，不必变成另一张大伤害卡 |
| 导航、加热餐包 | 分别提高移动路线收益、主武器短爆发；不是常驻加速或无条件全场攻击 |
| 取餐钩 | 可扩展奖励回收，但自动拉技能仍需防无限触发、补给组排他；武器不被误拉换装 |
| 派单终端 | 明确的喘息窗口；保护刷新节奏，不让无限停刷取代清扫 |
| 加急印章、补给券 | 提供收获选择和下一次技能机会，奖励不偷改伤害 |

核心战斗通过后再加入：

1. 小任务与技能/武器变体解锁，任务进度来自真实事件。先解锁玩法侧差异，慎加永久伤害和付费成长。
2. 少量精英与波末目标，让清扫顺序变化，而不是只加血量速度。
3. 连续切换夜市场景，角色与奖励保留，先做视觉变化，再决定是否加入地形机制。
4. 以约3–4分钟标准局和保留无尽挑战作为候选结构；最终是否分模式需看90秒验证关的结果。

| P0-2 | 约90秒、三波验证关；队列/散群/追逐/特殊组 | 不看说明也能感到建立压力、清扫、收获、下一波；至少有可辨认的取卡路线 |
