# V2 战斗核心实现与接入

规则分区 `night-market-2.0`。纯 TypeScript 模拟，无 DOM、WebAudio 或本地存储依赖；同一随机种子与固定输入序列可重放。坐标沿用 1280×720，碰撞区见 `core/config.ts`。每次 update 分为最多 1/60 秒逻辑步；异常非正时间忽略，单次调用超过 1 秒截断，避免宿主传入巨大值阻塞。

## 对外接口

- `new Game(seed?)`、`reset(seed?, practice=false)`：重置生命、默认取餐夹、种子和全部事件。
- `update(dt,input)`：移动意图 x/y，归一化后按加速度改变速度。
- `drainEvents()`：读取并清空事件。ID 在本局唯一，伤害事件 `victimId=0` 表示玩家。
- `setWeapon(kind)`：试验场换装，保留已发投射物及既有冷却，至少等 0.25 秒。
- `triggerSkill(kind)`：立即触发一个技能，效果由 `skills.ts` 管理。
- `spawnEnemy(kind, position?)`：生成敌人。练习模式立即激活，正常模式保留 0.6 秒预警。
- `clearArena()`：移除敌人、道具、武器包、投射物、区域和当前攻击，保留玩家生命、武器及身上状态。
- `healPlayer()`：存活时补到最大生命，仅对实际恢复量发事件；死亡后须 reset。
- `setPractice(bool)`：停止自然敌人、技能、武器刷新；练习仍正常扣血、死亡。正式存档由宿主依据 practice 排除。

## 生命与时序

玩家 100 HP；包子 30/接触8，外卖盒60/接触12/冲刺20，大碗面120/接触18。阶段不扩大血量和伤害。实际受伤开启0.75秒全局保护。多接触按连续接触时间、伤害由高到低、稳定ID排序。零HP才失败，失败后不继续模拟。

同一步先移动，更新技能与拾取，换装与武器伤害，再检查仍存活敌人的接触。伞在可见的前方弧带拦截一个目标并反击32；存活目标推开24，目标自身抑制0.15秒。伞没有全局保护；气泡抵消一次并开启0.75秒保护。全局保护中不消耗防护。

`damage` 事件携带唯一 id、victimId、source、amount（实际损失）、nominal（标称）、time、x/y。分数事件与伤害事件分离，HP归零仅计一次击败，支持渲染器将同一目标多来源伤害分行堆叠。

## 武器实现

参数表导出为 `WEAPONS`（range/windup/cooldown/active/damage/limit/width）。默认取餐夹20单体窄刺；纸袋三路16共享去重；飞筷按真实贯穿顺序36/28/22；汤灵有限转向及寿命、两个不同目标32/24；短刀120°弧24最多两目标；餐盘去程22最多两次、回程18一次，同敌可各阶段一次；伞前方反击32；尺剑长前摇窄线52最多三目标；餐盒固定落点延迟0.65秒范围44最多四目标；符册每0.1秒跳近邻30/22/16，不以击杀作为跳转条件。

攻击锁定同一目标；前摇仅限速修正朝向，释放后锁定。失效目标取消并至少等0.15秒。射程外不空放。移动不因攻击暂停。热包只使之后新建立的冷却乘0.8，不重置旧冷却。投射物全局上限12，汤灵/餐盘每种最多一个，待落地餐盒最多两个。换装不能清空既有冷却或累积无限弹道。

## 武器包

第一包15秒；后续22–28秒尝试，场上最多一个自然包和一个退换包。安全落点避开玩家160范围、敌人及冲刺路径、技能道具。无放回袋随机，排除当前武器；无法放置延后1秒重试。

触碰即换装。原武器形成10秒退换包，前2秒锁定；解锁后必须离开拾取圈再进入。自然包20秒到期。吸取技能不处理武器包。重复同款不升级、不刷新冷却。
