# V3 核心接口与玩法变更

规则区分为 `night-market-3.0`。V2存档由存储层按旧规则备份保留。

- 玩家持续近似同向输入1.8秒后，0.6秒内平滑从1.00提升至1.12速度；方向相对起始偏转超过约10度、停下或顶墙会重置。路线速度仍独立生效。
- `Game.dash():boolean` 沿最近输入方向触发0.18秒、2.5倍基础速度冲刺，3秒冷却；冲刺期间接触与敌弹均不扣血，不消耗气泡。边界继续约束。重置/清场清理冲刺及敌弹。
- `player.sprintTime/sprintMultiplier/sprintDirection/dashUntil/dashReadyAt/dashDirection` 在Game始终初始化；共享类型保留可选标记兼容旧fixture。
- 四阶段敌人上限45/70/90/100。包子基础40.5、盒35.1、碗24.3单位/秒，远处带分散游走，近处局部追逐，使用64单位空间桶作软分离。血量与接触伤害保持V2。
- 盒怪仅一个同时预警/冲刺，预警1.1秒、冲刺205.2单位/秒、0.5秒、恢复1.5秒，4秒接近周期。
- 碗怪正式模式30秒后出现并攻击；练习可立即测试。`shotWarnUntil` 为0表示未预警，否则持续0.9秒，`shotAngle` 在开始预警时锁定。眩晕取消本次预警。射击后至少5秒等待。
- `state.enemyShots` 为敌弹，半径6、速度90、伤害8、最多12、寿命7秒。数据含id、ownerId、x/y、px/py、vx/vy、bornAt/expiresAt。连续扫掠检测命中，命中保护中的玩家也消耗弹体，避免保护结束重复扣同一弹。
- 玩家接触与敌弹同一步统一按接触时刻、较高伤害、稳定ID排序。伤害保护和气泡共用既有规则。
- 武器总伤害由武器模块决定，核心将一次武器命中分成最多五段真实扣血，每段上取整总额/5，最后修正余量；实际剩余HP不足提前结束。每段有独立damage.id、实际amount、可选burstIndex(1起)/burstCount。技能保留单次事件，击败仅一次。
- 武器首包4秒，后续10–14秒，场上最多两个自然包和一个退换包。自然包距玩家90–270范围、安全且不与已有道具冲突；退换2秒锁定/离圈重入/10秒寿命规则保留。

验证：120项自动化测试通过，包括10武器真五段/过量、冲刺防护、远程预警锁方向/慢弹/上限、早期群体密度、近处掉落，以及10分钟模拟的实体预算。数值仍需实际试玩校准；自动化不代替真机手感与视觉评审。
`CONFIG.player.minY=180` 只限制玩家脚点顶边，普通移动和冲刺共用这一边界；约117高的人物头顶至少63，位于58高HUD下方，怪物与场地顶边仍为100。
