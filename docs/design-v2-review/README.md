## 推荐的整体变化

从“移动躲避＋拾取技能”扩展为“**手持武器持续作战＋移动躲避＋拾取技能解围＋局内换武器改变打法**”。操作建议继续以单手移动为主，武器自动索敌和攻击，不额外增加瞄准、普攻或装填按钮。角色停下时双脚站稳，身体呼吸与握持武器；移动时有起步、踏步、重心变化和收步；攻击时由对应武器驱动上身动作。

“十款武器”按**包含默认武器，共十款**设计；“技能道具再多十个”按**现有三款保留，新增十款，总共十三款**设计。数量口径属于本轮建议，便于评审。

## 武器速览

十款武器属于同一个夜市世界，通过实物轮廓、材质、攻击路径和动作区分，不以十种颜色替代十种玩法。

| 编号 | 武器 | 主要玩法差异 | 主要视觉识别 |
|---|---|---|---|
| W01 | **伸缩取餐夹（默认）** | 近身精准短刺，稳定处理单个追兵 | 银色夹口、橙色握柄；短促白色夹击痕 |
| W02 | 纸袋气炮 | 前方锥形散射，擅长近距离扇面 | 牛皮纸袋与风箱；分叉气团和纸屑 |
| W03 | 打包筷发射器 | 窄直线穿刺，适合引怪排队 | 竹木长条；一根筷子穿过直线目标 |
| W04 | 保温壶蒸汽喷嘴 | 持续短程扫喷，攻击期间可移动 | 青绿保温壶；乳白蒸汽翻卷与凝露 |
| W05 | 封箱胶带枪 | 单体束缚后收紧，争取走位时间 | 琥珀胶带卷；缠带、绷紧、断带 |
| W06 | 送餐托盘飞轮 | 去程与回程形成两条攻击机会 | 搪瓷托盘；弧形回旋轨迹 |
| W07 | 折叠配送伞 | 前方短窗口格挡后反击，有方向性 | 橙白雨伞；开伞撑面和接触火花 |
| W08 | 手推车冲锤 | 沿直道推进；玩家本人不被带着冲刺 | 两轮推车、纸箱；轮印、颠簸与推撞 |
| W09 | 弹射餐盒 | 抛物线延迟落点，处理集群 | 弹簧餐盒；飞行弧、落点提示、米粒冲击 |
| W10 | 扫码电弧器 | 从首目标跳向近邻，适合密集小群 | 扫码器；短红扫描线、逐段蓝白电弧 |

详细参数、短板、动作、特效分镜、音效和判定边界见 [02_十款武器](02_十款武器.md)。所有数值均为首次试做建议，不是已验证的最终平衡。

武器方案仍需关注：**默认取餐夹是否合适；是否采用自动攻击；触碰武器包立即换装是否合适；B 方案的刀剑、法术方向是否合适。**技能最终取舍在动态试玩后决定。生命值制已按用户意见纳入后续设计，具体伤害、保护时长与回复供给通过样机校准。

确认前不改源码、游戏参数或部署产物。确认后的建议验证顺序为：先做默认武器＋站立/走跑动作；再用取餐夹、托盘和雨伞验证近战、远程与防御三种代表手感；通过后扩展其余内容。这是实施顺序建议，本次仍完整给出十款武器和十款新增技能设计。
