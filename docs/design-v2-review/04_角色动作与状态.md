# 角色动作与状态设计 · 待确认

> 最新覆盖：用户已确定生命值制，08 文档优先。普通受击不再必定播放失败坐地，应增加可继续移动的短肩震/表情反馈与保护状态；HP 归零才进入失败动作。本页原先“一击失败下只做护盾受击”的约束已作废。

本文是下一版设计稿，不是已实现功能。当前网页仍使用两帧跑步图集；本轮不修改程序、数值或线上版本。武器实际判定与技能规则以同目录的武器、道具方案为准，本文约定它们怎样体现在人物身上。

最新补充：07 文档提出包含刀剑与法术的 B 方案。本文原十种武器表和 286 项资源估算属于 A 方案；通用站走跑规范仍适用，B 方案替换的四款动作见文末，不能同时把 A/B 全部算进必做十款。

## 1. 人物应当给人的感觉

她是熟练、轻快、有点俏皮的夜市快递员。平时保持能够马上起跑的站姿；走路像在穿过人群，快跑时身体略微前倾、配送包有重量；攻击像临时把身边的配送工具用得很巧，不突然变成持重枪的士兵。

继续使用暖色手绘、清晰棕色轮廓、柔和明暗块面。头盔、脸、马尾、橙夹克和青绿包的轮廓必须在手机实际尺寸下可辨认。身体不作持续夸张拉伸；攻击的力量主要来自肩、肘、手腕、包带和道具的动作。

本轮建议保持单手移动：摇杆、倾斜或键盘决定走位，武器自动寻找有效目标并攻击。攻击、拾取和换武器都不强制停步，不引入额外冲刺键、攻击键或技能键。

## 2. 必须修正的当前观感

| 当前问题 | 下一版目标 |
|---|---|
| 松开移动后仍停在腾空跑姿 | 减速结束后回到双脚有明确落地关系的站姿，双膝微松，手里真实拿着当前武器 |
| 跑步只有两张姿态互换 | 有落脚、承重、蹬地、摆腿和短暂腾空的连续过程，马尾与包的摆动略滞后 |
| 人物与战斗效果缺少身体联系 | 每种武器都从相应手位或道具出口释放；夹、推、抛、喷、撑伞等动作不同 |
| 转向主要靠瞬间翻图 | 身体先转肩再换脚，马尾与包随后跟上；不因每帧选目标反复左右抽动 |
| 道具拾取只有特效 | 有短促的收手、触碰或提肩回应，保持跑动，不弯腰长时间打断走位 |

“站着”指下半身稳定站立。有敌人进入攻击条件时，上半身仍可站姿攻击；无有效目标时才恢复完整持械待机。

## 3. 动画层与运行方向

建议把角色组织为脚点、下半身、躯干/头、手臂、手持武器、后挂包/马尾、前景道具与特效几个表现层。它们共享同一脚点，不各自漂移。具体采用分层逐帧或骨骼加关键帧，需在确认美术规格后选定；不在本轮承诺现有两张图片可以直接生成完整动作。

| 表现层 | 职责 | 不得改变 |
|---|---|---|
| 脚点与阴影 | 标识角色在地面的真实位置；阴影随步态小幅收放 | 不跟随头部摇摆，不能扩大或缩小碰撞半径 |
| 腿部与腰 | 站立、走、跑、启动、停步、侧移/倒步 | 攻击时仍按玩家输入更新移动 |
| 胸肩、头、手臂 | 持械、瞄准、十种攻击、换装和拾取回应 | 不用整个人旋转代替转身，不让头盔剧烈抖动 |
| 配送包、马尾、衣摆 | 体现速度与惯性，约比躯干晚半拍 | 不遮住脚点、敌人冲刺预警或武器出口 |
| 武器与前后遮挡件 | 与握点、释放点、收回点一致 | 武器不会先发弹，人物稍后才做动作 |
| 特效 | 呈现风、纸、蒸汽、胶带、电弧等物性 | 不拿装饰粒子代替真实判定提示 |

四个运行朝向采用前右、前左、后右、后左的 3/4 视图。先制作前右和后右两套完整方向，左右方向可以在审校后镜像。不能把正面直接翻成背面。

镜像必须检查胸口图案、可读文字、武器结构、惯用手、斜挎包带和包的位置。可读文字独立绘制，不反字；前后方向重新配置包和手臂的遮挡层。确需固定右手的武器，左右持械动作单独补画，不为省图让左右手凭空交换。

移动方向控制腿和脚；攻击目标控制肩与手。目标位于身体后侧时，采用转肩、侧步或短倒步姿势，不把向右移动的角色画成向左全速奔跑。自动瞄准角度为连续方向，角色只有四个主要朝向；武器不能因为朝向分档而漏打斜角目标。离方向分界约 10° 才切下一档，并保留约 0.10 秒的朝向稳定窗口；这是初拟表现参数，不能延迟玩家移动。

## 4. 行走、站立与起停

下表速度百分比以角色当前允许的最高速度为参考，只用于选动画。初拟阈值需在真机上调节，不能为了播放某个动作而修改输入或移动速度。

| 状态 | 进入与退出 | 动作设计 | 建议循环/帧数 |
|---|---|---|---|
| 持械站立 Idle | 真实速度低于约 5%，并稳定约 0.10 秒 | 双脚错开站稳，轻微呼吸，手持当前武器；每 3–6 秒可眨眼或看路，不持续左右摇摆 | 4 帧轻呼吸，约 1.6 秒循环；眨眼为稀疏附加动作 |
| 启动 Start | 有移动意图且速度离开站立区 | 前脚发力，肩先向移动方向带出，包略后拖 | 3 帧，约 0.10–0.14 秒；可被反向输入立即接管 |
| 慢走 Walk | 约 5%–45% 速度 | 脚跟到脚掌承重，小步幅，无夸张腾空，身体上下起伏小 | 8 帧；步频按实际速度缩放 |
| 快跑 Run | 高于约 55% 速度；回到 45% 以下再转慢走 | 蹬地、交叉腿、前摆腿、落脚明确，身体前倾，包带拉紧；头保持相对稳定 | 10 帧；满速约 0.48–0.56 秒完成左右脚一循环 |
| 停步 Stop | 移动意图归零且正在减速 | 前脚轻踩住，后脚收回，身体回正，包向前轻摆后归位 | 3 帧，约 0.10–0.16 秒；逻辑已停止时不得滑行等待动画 |
| 转身 Turn | 新方向越过主要朝向边界 | 肩先转、支撑脚转、后脚跟上；快速反向有更明显的重心转换 | 3 帧，约 0.08–0.12 秒；不锁输入 |
| 侧移/倒步 Strafe | 腿部移动方向与攻击朝向相反 | 身体保持看向目标，短促侧步或交替倒步，避免膝盖折向错误方向 | 6 帧循环，按真实速度驱动；不是新增操作模式 |

键盘通常直接进入快跑，摇杆小幅推动可以慢走；倾斜模式也根据实际速度选择，不必额外设置“走/跑”按钮。Walk/Run 的阈值保留滞回，避免临界速度一帧走、一帧跑。

脚步循环相位尽量连续：从跑到走按当前支撑脚进入相近姿态，不能每次从左脚第一帧重新开始。角色到边界后真实速度为零，脚步也应停下；不得出现原地狂跑但脚点不动。墙边持续输入可采用轻微探身站姿，不增加挤墙音效。

## 5. 十种武器的专属动作语言

以下名称与类型对应武器方案。帧数是关键绘制帧建议，不是攻击频率；实际出手间隔和有效范围由武器规则决定。动作中的释放、命中、回收等时刻必须有明确事件标记。

| 武器动作类型 | 持械待机 | 出手与身体回应 | 移动时如何保持自然 | 建议关键帧/每原画方向 |
|---|---|---|---|---:|
| 取餐夹近刺 | 餐夹收在腰前，夹口微闭 | 肘收紧→肩带出→夹口前探并咔哒合拢→弹回；小而清楚，不像挥剑 | 前刺发生在腰以上，双腿继续当前步态 | 8 |
| 纸袋锥形散射 | 纸袋双手托在胸前，袋口朝外 | 袋身压瘪→袋口张开→双掌推挤，纸风和餐巾从袋口喷出→袋身鼓回 | 后坐只作用于肩和包，不把角色脚点推后 | 7 |
| 打包筷直线穿刺 | 装筷器斜放在身前，短而轻 | 手腕对齐→短促扣动→筷影直出→另一只手拨动补位；动作利落 | 转肩瞄准，腿部可以侧移，不全身僵直端枪 | 6 |
| 蒸汽壶持续喷射 | 一手持把、一手稳住壶身/喷嘴 | 壶嘴抬起→阀门打开→肩部小幅承压保持→闭阀卸汽；喷射期间有短循环 | 重心随移动变化，喷嘴转速平滑，热汽不得从脸或包中凭空出现 | 8，含 3 帧持续循环 |
| 封箱胶带束缚 | 胶带枪贴腰，空手预备拉带 | 扣扳机→手腕甩出胶带头→牵出可见胶带→切断→收腕；切断帧与封口声同步 | 上身略侧向，伸出的手与胶带连线同向，不强制拉住角色 | 8 |
| 托盘回旋 | 托盘竖在臂侧，另一手留出空间 | 手腕蓄旋→侧抛→空手等待→接回并缓冲；回盘时必须有接物动作 | 抛出后恢复摆臂；回收优先短接物动作，不把脚步改成站姿 | 10，含投出与接回两段 |
| 配送伞方向反击 | 伞收起靠近肩，伞尖向外 | 握柄前送→伞骨“啪”地撑开→双肩短暂承压→伞面弹回反击→合伞 | 防御阶段只是上半身稳定，玩家仍能离开危险；没有全身无敌站桩姿态 | 9 |
| 手推车滚动冲锤 | 折叠车把握在身侧，车体可读 | 抽出折叠车→双掌前送→车轮落地滚出→手臂收回；重感来自双掌和轮子 | 不是角色自身冲刺；手推结束后立刻恢复持械跑姿 | 10 |
| 餐盒抛物线 | 餐盒从包侧抽到手中，盒盖闭合 | 侧身后摆→抬臂上抛→指尖脱手→手臂顺势下落；抛物线起点与手指一致 | 腰以上完成抛掷，目标位置在投出时确定，不因后续转身使餐盒拐弯 | 9 |
| 扫码器连锁电弧 | 扫码器在胸前，手指自然搭在握柄 | 举起瞄准→扫描头短亮→轻点触发→手腕短震→收回；身体反应轻巧 | 主电弧起点固定在扫描窗，后续连锁在敌人间发生，不要求人物反复转身 | 8 |

每个动作至少有一个区别于其他武器的清楚姿势：前探、挤压、扣动、稳壶、甩带、侧抛、撑伞、推车、上抛、抬扫。不能仅换手中图片，沿用一段通用挥手。

默认武器在站立、走路、跑步、攻击、失败前都应真实可见。武器可以适当简化细节，但轮廓和主要握点不能只靠 HUD 图标表达。

## 6. 出手节奏与动作事件

每个攻击动作拆为准备、有效/释放、收回三段。初拟普通短动作可按约 20% / 20% / 60% 分配表现时长；这是美术节奏参考，不能反过来擅改武器攻击间隔。持续喷射、托盘回收、伞反击使用各自明确阶段，不强塞进同一个三段模板。

关键同步要求：

1. 武器前摇开始时选定本次目标，准备动作只对该目标小幅跟随；在释放标记处锁定本次出手方向，有效帧不能突然转到角色身后。具体索敌例外服从战斗总规则与武器说明。
2. 投射物、喷口特效、胶带头从对应武器的释放点出现。同一事件驱动画面与声音，不能以“第几张贴图”单独决定伤害。
3. 伤害/控制命中后才播放命中反应；出手声与命中声区分。空挥只有动作和空气声，不播放击败声。
4. 无有效目标时不持续空挥。持续武器按规则结束后回持械待机，不保留喷射姿态。
5. 攻击表现不使用全局停顿。需要力度时，对手臂/武器做约 20–40 ms 的视觉强调，脚点移动、敌人预警和输入处理继续。
6. 关键事件在掉帧时仍只能触发一次；减少动态模式可省摆动、碎屑和震动，不能省略有效范围、释放方向与护盾耗尽反馈。

## 7. 换武器、拾取与附加状态

| 状态 | 表现方案 | 规则边界 |
|---|---|---|
| 换武器 Equip | 空手把旧工具收向包侧，新的工具提到握点；约 0.20–0.30 秒上身过渡，配短促工具声与 HUD 名称 | 只在武器方案确定的换装成功时触发，不自行新增确认按钮；不锁脚，不提供无敌 |
| 技能拾取 Pickup | 小幅收手/提肩配合道具从地面向手或包侧“收取”的短轨迹，约 0.12–0.18 秒 | 道具规则已在触碰时生效，不能等收取动作结束才救场；攻击中允许只用肩/表情回应 |
| 护盾挡击 Guard-hit | 肩部短震、头盔轻点、脚步不断；护盾包材明显受压，再弹开或破裂 | 只有实际挡住一次危险时才播放；永久一击失败基线不变，护盾规则由道具文档规定 |
| 被限制/缓速 Slowed | 如后续确有玩家缓速效果，降低步频与步幅、身体更沉；保留攻击上身 | 当前汽水只减速敌人，本轮不因此新增玩家减速、疲劳或体力惩罚 |
| 技能增益持续 Buff | 通过包/工具的局部光泽、附着物和小图标显示，腿保持自身步态 | 速度未改变就不加快脚步，不因特效转圈而让人物转圈 |
| 倒计时 Ready | 双脚站定，握好当前武器，最后一拍轻压重心 | 倒计时结束才恢复模拟，不先走半步抢跑 |
| 失败 Fail | 碰撞瞬间惊讶→工具收近身体→退肩/坐倒或蹲下，包里跳出少量纸袋，约 0.45–0.65 秒 | 失败判定即时冻结对局；后续为表现，不能继续移动、拾取、计分或输出新攻击 |
| 结算 Result | 失败动作末帧保留在战场后方，小票结算弹出；可有不遮挡按钮的表情反应 | 生存模式不添加“胜利庆祝”假动作；再来一局清空上一局附件和残留特效 |
| 暂停/后台 Pause | 保留当前姿势、武器位置和效果相位；恢复倒计时保持静止 | 不循环脚步、不继续收回托盘；不补播后台积压的动作或音效 |

换武器与已出手实体：尚未到释放点的旧攻击应取消并切入换装；已经离手的实体按武器方案继续到自己的寿命结束，不能被换装无故瞬移到新武器。无论采用哪种飞盘回收规则，旧武器回收不能覆盖新武器的持械姿势；必要时表现为旧托盘飞回配送包。

## 8. 状态优先级与冲突处理

这是表现状态的优先级；实际伤害与拾取顺序仍由玩法规则统一裁定。

1. **暂停/后台/横屏阻挡**：冻结当前游戏表现时间，保存正在进行的姿势；不产生新的战斗事件。
2. **已经确认的失败**：终止当前攻击和换装动画的后续出手事件，播一次失败反应。它不能被拾取装饰、挥手或低优先级反馈覆盖。
3. **护盾实际挡击**：若规则判定此次不会失败，插入短促肩部反馈；持续喷射等武器是否中止由武器规则决定，不能仅由受击动画强制取消。
4. **换装成功**：切换手持物与握点；上下身分层，移动继续。不能把同一枚武器拾取事件播放两遍。
5. **本次攻击的关键有效/释放/回收段**：保持关键动作完整与物理来源清楚。技能逻辑可以同时触发，但低优先级拾取手势不得把喷嘴或抛物手切走。
6. **普通拾取回应与非关键表情**：在空闲上身层播放，繁忙时简化成肩/头/小图标回应。
7. **基础站立、走、跑、起停与转身**：一直依据角色真实运动状态更新。上述上身状态不会取消下身运动。

同一时刻发生技能拾取和危险接触，先由玩法系统决定是清除敌人、护盾挡击还是失败，再选择相应表现；不得先播失败后又因为拾取而“复活”。

## 9. 美术交付量与方向审校

建议先做完整动作表，再逐武器验收。不要要求图像生成一次产出一张含数百小人的大图集；应按动作、方向和部件拆分制作，人工检查握点与帧间连续性。

共同动作每个原画方向建议：Idle 4、Walk 8、Run 10、Strafe 6、Start 3、Stop 3、Turn 3、Equip 6、Pickup 4、Guard-hit 5、Fail 8，共 **60 个关键绘制帧条目/方向**。前右与后右两套共 **120 条目**。左向镜像审校产生的修正帧另列，不以“自动镜像”抵消应补画的手持或包带。

十套武器专属动作按表中建议合计 **83 条目/原画方向**，两套方向共 **166 条目**。两部分合计为约 **286 个关键绘制帧条目**，其中有可复用的身体层，不是要求 286 张完整全身大图。喷射循环、托盘接回等分段不能漏交。武器本体、投射物、特效纹理及镜像修正另计。

待确认后优先做一套前向完整人物 + 默认武器，检查站立、移动、攻击能否自然融合，再推广到背向与其余武器。该顺序是制作安排，不是减少用户确认后的目标范围。

每个交付单元标注：动作、方向、帧序、持续时间、脚点、左右握点、释放点、武器前后遮挡、有效事件标记、是否可镜像。导出保持统一原点和逻辑尺寸，透明边距不参与身体尺度；不得每帧各自紧裁后直接居中，导致头和脚不断跳位。

## 10. 音效与视觉节奏

脚步只在真实落脚时轻触发，不逐帧触发；跑步比走路更短、更紧，音量低于技能和敌人冲刺预警。角色贴边停止时不持续播放脚步。包带/工具轻响可每隔几步出现一次，避免重复金属噪声盖住重要信息。

十武器分别使用夹口咔哒、纸袋挤压、竹筷轻弹、阀门蒸汽、胶带拉扯切断、托盘破风与接盘、伞骨撑合、车轮咕噜、餐盒扣盖和扫码短音。物体动效先说明材质，再加少量夸张能量声；同一条通用激光声不得套满十种武器。

攻击音跟随释放标记，命中音跟随真实结果；技能拾取音只提示一次。多人声部拥挤时优先保留危险预警、护盾破裂、失败、关键拾取，压低脚步和装饰声。减少动态关闭震屏、抖动与过多飘纸，但保留物体的关键动作。

## 11. 性能与验收

逻辑仍按固定时间步工作，角色表现可以按动画自身帧率播放；跑步画面不必为每个逻辑帧准备贴图。动画事件以时间标记消费，不依赖显示器刷新率。手机低画质可减少次级包摆、马尾和装饰颗粒，不把人物退回“静止跑姿”。

同屏只加载当前场景共用人物层及所需武器资源；切换资源时必须有预加载安排，换武器不能让角色空白一帧。实际内存、图集尺寸与解码峰值在制作后实测，本文不凭关键帧数量虚报包体大小。

确认后开发验收至少包括：

- 无目标松手约 0.2 秒内回到双脚落地站姿；停在地图边界也不原地跑。
- 小幅摇杆走、大幅摇杆跑；左右脚交替，走跑转换不重置成抽搐步；输入响应不为动画让步。
- 十种武器的持械与出手动作可在不看名称时区分，武器出口、手、投射物方向一致。
- 跑动攻击不中断脚步；倒退/侧移时膝盖、脚尖与移动方向合理，人物不高速左右翻面。
- 拾取救场的逻辑即时有效，武器换装无假无敌；既有飞出物不突然消失或跑到新武器握点。
- 有护盾时播放挡击，无护盾致命碰撞只播一次失败；不出现先失败再继续攻击。
- 暂停、后台和旋转恢复保留状态；无积压脚步声、连射声或高速追赶动画。
- 前后方向、左右镜像、手臂穿模、包带与文字逐项审校；手机横屏缩小后仍能识别手持武器和脚点。
- 在至少 60 敌人和密集技能场景下，优先保留输入、命中时序和危险提示；记录真机帧率与音画延迟，不以桌面短时测试替代手机验收。

## 12. 本轮需要确认的设计方向

建议确认：自动攻击是否作为基础操作；站立/慢走/快跑与四向角色是否采用本方案；十种武器是否都有独立攻击动作；换装与拾取是否坚持不锁移动；一击失败是否继续保留，仅由明确的临时护盾提供额外容错。
