# 五类武器补齐与道具动态评审

日期：2026-11-18。依据用户最新反馈：武器考虑远程、近战、暗器、刀剑、法术；道具需要开发后看实际效果才能确定，继续分析。

## 1. 首轮覆盖与缺口

首轮已覆盖近身工具、远程器械和投掷暗器。蒸汽壶是机械喷流、扫码器是工具电击，有特殊效果但还不是独立法术；也没有明确的刀剑。这两类需要补齐。

五个词并非互斥：“近战/远程”描述距离，“刀剑/暗器”描述武器与出手形式，“法术”描述力量来源。长剑可以是近战，法术也可以是远程。因此五组用于展示，每把再标距离、路径、目标数、动作和风险。不能把同一机制换颜色当成不同类别。

## 3. 刀剑必须有斩击和收势

### B05 拆箱快刀

短宽卡通实体刀刃、橙色防滑柄、青绿护套、胶带卷形护手与配送封签。来源是拆箱工具，但手机上必须看得出刀刃，而非模糊小尖片。

候选参数：半径约 65 单位、约 120° 斜斩弧，前摇 0.12 秒、有效窗 0.12 秒、冷却约 1.20 秒，一次最多两个目标。出手时定朝向，有效窗不能转成 360°。它比默认夹子更宽、更短，适合近身切口，仍怕包围。

动作是收腕→肩肘带刀→斜切→短收势；连续两次可交替正反斩，但不增加连击按钮。空挥只有短风声，命中才有硬音和食物碎屑，不用血液或人体伤口表达力量。

### B08 签收尺剑

包裹量尺化成实体长剑：剑脊刻度、橙柄、签收印章形护手，末端挂短收据。配送身份体现在材质、装饰与习惯，不要求它仍像一把普通尺子。

候选参数：0.32 秒可见蓄势，然后打出约 125 单位长、24 单位宽的近身劈线，一次最多三个目标，冷却约 2.40 秒。刀锋对应判定区域，斩光只是短残影，不是飞出半屏的剑气。与飞筷的区别是近身实体出刃、重前摇和明确收势。

蓄势只作用于上身，脚步继续响应输入，无无敌帧、不强制站桩。角色提剑→直劈→压腕收势，不能出招后瞬间切回待机图。

## 4. 法术必须有施法和生效过程

### B04 汤灵保温壶

保留青绿壶身、橙柄和金属盖。施法先在壶口形成小汤花符印，蒸汽凝成有眼睛、汤勺尾巴的卡通汤灵，再离壶追击。它是有形法术实体，不是几何点或普通蒸汽换色。

候选参数：前摇 0.30 秒，选敌范围约 180 单位，汤灵最多存在 1.20 秒、最多命中两个不同目标、同时最多一个，冷却约 2.60 秒。追击有转向限制，目标失效后最多重选一次；无合法目标自然散去，不常驻跟宠、不全图追杀。命中后身体变小，耗尽散成汤汽。

动作是揭盖→托壶→送灵→收盖，声音使用短沸腾、呼气和瓷勺清音。它与 S04 诱饵不同：汤灵主动攻击，诱饵固定在地面改变怪物目标；也不再使用持续喷嘴伤害。

### B10 派单符册

青绿皮套夹着配送单据，配橙封签和小印章。角色翻册、捻出订单符纸，在首目标处盖小符印，再把下一张单沿短符线送往邻近目标。需要看见纸、印、符号与逐个生效过程，不把旧电弧改紫色就称法术。

候选参数：前摇 0.28 秒、首目标约 150 单位、相邻跳转约 80 单位、最多三个不同目标，逐跳间隔约 0.10 秒，冷却约 2.60 秒。首目标在前摇中失效则按统一规则取消；已开始的跳链从上一命中位置查找合法近邻，无下一目标即收尾，不无限等待、全图追踪或回跳。

角色翻单→捻符→送出→收册；翻纸、轻念般的音色与盖章声形成节奏，可不用重复真人台词。停止移动时下身站稳，上身施法；无目标时整个人回到持械待机。

### 法术武器与技能道具的职责

法术武器占常驻武器槽，按周期反复施放；技能道具是拾取后额外触发的战术能力。两者都可有特效，但获取方式、占槽和频率不同。所有新参数只作为动态样机起点，未经过试玩，不是最终平衡。

## 5. 道具改为动态试玩后定稿

S04–S13 全部保留“候选、待动态试玩”状态。静态图只能确认主题、实物形象和功能大意，不能确认操作感、视觉遮挡、音量舒适度、救场价值或性能。

后续建议建立可运行的独立试验场，能够自由切换 **10 个新增技能＋3 个现有技能**、更换武器、摆出敌群、重置场景，并切换正常速度/半速查看。试验场控件不搬进正式 HUD，不产生正式纪录。正常速度判断手感，半速只检查时序。

每个道具至少评审三种情境：

| 场景 | 观察问题 |
|---|---|
| 空场拾取 | 是否看懂发生了什么？无目标反馈是否合理？ |
| 紧迫场景 | 是否真能完成声称的作用？失败原因是否清楚？ |
| 多效果叠加 | 是否挡住脚点/预警、声音过吵、规则冲突？ |

重点组合：气泡＋伞、路锥＋冲刺、手铃＋近身剑、取餐钩＋补给箱、热包＋短刀/长剑/法术、暂缓增援＋阶段变化、积分倍率＋延迟落地攻击。

试玩后逐项标记“保留 / 调整 / 替换 / 暂缓”，记录视觉、手感、战术和性能。可先用三个代表道具验证试验场流程，再补齐其他七个；最终评审仍覆盖十个新增道具，不用三个演示代替完整名单。

## 6. 本轮结论

建议采用 B 方案补齐五类武器，默认仍为取餐夹；差异来自攻击过程和风险。自动攻击、单手移动、真实站立/走跑和攻击不锁脚继续作为推荐基线。

道具最终取舍留到动态试玩，不要求现在凭图片冻结数值。用户当前要求“继续分析”，本轮继续完善方案和试验场需求，未提前修改源码或替换线上版本。
