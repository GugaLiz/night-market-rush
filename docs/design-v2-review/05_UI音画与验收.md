# 界面、音画与后续验收设计

> 最新覆盖：顶部需新增常驻玩家血条；命中敌人和玩家受伤分别显示数字。08 文档与新的血条战斗图优先于本页旧 HUD 和一击失败描述。敌人血条和飘字遵守限量、按对象合并及可读性要求。

## 1. 战斗画面怎样容纳武器和更多技能

顶部继续保留得分、时间、阶段与暂停。左下或右下仍由用户的操作手位决定摇杆位置；新的武器信息条放在摇杆对侧，属于只读信息，不是需要点击的攻击按钮。

武器条显示“实物小图＋短名＋下次攻击的细刻度”，例如“取餐夹”；换装成功才短暂显示完整名称和打法词，约 1.2 秒后恢复紧凑样式。禁止每次攻击弹出大号武器名。W07 伞的有效格挡主要看人物伞缘，W06 飞盘离手主要看实际托盘，不能让玩家只盯 HUD 才能知道状态。

加热餐包把“急速”挂在武器条上。其他持续状态独立放在屏幕边缘的短图标带：气泡优先显示“1次 / 剩余秒数”；其他图标有外圈计时和固定位置。最多显示 6 个紧凑状态图标，按“防撞 → 滑板 → 路线 → 增援暂缓 → 加急 → 路障/诱饵”排序；更低优先级用场景物件自身的到期提示表达，不把关键防御藏成“+N”。瞬时手铃、吸取和补给提示不长期占槽。

同一时刻最多一条短提示与一条防御紧急提示；新获得技能名称可排队短显，但不延迟技能实际生效。护盾破裂、换装成功和失败原因不能被普通分数提示挤掉。

## 2. 地面物件要一眼分清

| 类型 | 轮廓与材质 | 玩家看到的信息 |
|---|---|---|
| 当前手持武器 | 真实工具握在手里，大小服从动作 | 我正在用什么 |
| 自然武器包 | 长纸箱托架＋展示武器＋短名 | 走过去会换成什么 |
| 暂不可捡的退换包 | 合盖包裹逐渐打开，小锁扣计时 | 现在不会立即换回 |
| 普通技能 | 较小实物＋地面短光圈，无长箱座 | 触碰即触发什么 |
| 补给三选一箱组 | 三件物品共享小纸箱与“取一件”小票 | 只会拿其中一个，其余会收回 |
| 临时场景效果 | 路锥、诱饵、路线有实物或范围提示 | 这个位置会影响什么 |

不能用武器包与技能仅有不同颜色的同一种球体。道具图片本身保持可辨认，短名不盖住怪物脚点；名称重叠时优先显示距离玩家最近的两件。

## 3. 特效语言与遮挡控制

武器效果尽量保留物性：金属夹是短亮痕、纸袋是松散纸风、筷子是一根直线实物、蒸汽是卷曲白汽、胶带是琥珀窄条、托盘是回旋实体、伞是前方撑面、推车是轮印、餐盒是抛物线与落点、扫码器是逐段电弧。即使去掉颜色，也应能凭形状和运动区分。

玩家攻击可以明亮，但敌方冲刺预警仍使用更明确的警示轮廓与方向箭头。红色扫码线只留在小扫描窗和目标框，不画成贯穿地面的红色危险线；地面导航使用虚线与站点标记，和敌人冲刺长条箭头区分。

重要视觉层顺序：地板 → 地面范围与路线 → 背后特效/投射物 → 按脚点排序的角色怪物 → 前景手持与短命中特效 → 小型状态/数字 → HUD。技能粒子不覆盖敌人脚点与伞的有效边缘，必要时减低装饰特效透明度。

全屏闪白不用于普通攻击。大反馈优先使用局部明暗、工具形变、短击停感的动画姿态与声音；本轮不建议暂停全局模拟制造打击停顿，以免改变躲避和重力手感。震动设置关闭时，危险提示和命中反馈仍然完整。

## 4. 音效与节奏

默认武器声音最克制；持续蒸汽、轮子和胶带必须有开头、持续/收紧、停止段，暂停、换装和失败时不留下循环残响。十把武器的主要音色分别使用夹合、纸噗、竹啪、汽嘶、胶带拉扯、金属盘嗡、伞骨啪、轮子咔隆、饭盒落扣、扫码滴与短电噼。

建议声音优先级：失败/危险冲刺提醒 → 防撞耗尽 → 技能关键触发 → 武器命中 → 武器出手 → 脚步/装饰。短时间大量命中合并音量而不是叠出刺耳峰值；最大声部预算与衰减参数需开发后听测。先保留现有音乐方向，通过配器与混音为更频繁的武器声音留空间。

角色动作音与有效帧同步：夹口闭合、伞骨展开、轮子落地、餐盒离手、托盘接回都有明确时点。错过目标不播放命中声。脚步按实际落脚触发，站立时无脚步；减少动态不等于静音。

## 5. 制作规格与预留平台

角色方向、分层和关键帧清单以动作文档为准。概念板只用于批准形象和姿势，不能把一张多格概念图直接切成完整动画；正式制作时须统一锚点、握点、释放点、阴影与透明边距，并逐帧审查。

每个武器和技能都应有稳定编号、显示名称、规则说明、动画事件、特效、音效、地面展示、HUD 图标与说明卡。编号 W01–W10、S01–S13 作为后续平台共享的内容身份，规则不依赖网页按钮或 DOM。

继续沿用固定逻辑世界与独立渲染分辨率。浏览器、Android/iOS 和微信小游戏的效果数量可分级，危险提示和命中规则必须相同。手机正式包、微信工程和真实传感器适配仍是后续平台工作，概念设计不代表完成适配。

## 6. 确认后的验收清单

- 静止时双脚站稳，有持械待机；边界停住不原地跑。走、跑、起步、停步和转向能从轮廓看出区别。
- 每把武器至少测试站着打、边走边打、转身打、目标失效、连续换装、暂停恢复；击发从正确握点产生，脚点不会被攻击动画拖走。
- 武器出现、自然换装、退换包解锁/重入、吸取排除武器、剩余投射物和冷却继承都符合说明。
- 每一项技能分别测试单独触发、同类重复、和三种旧技能组合；重点检查伞＋气泡、路锥＋冲刺、胶带＋手铃、取餐钩＋三选一补给、加热包＋换装。
- 防御成功只消费应消费的一次效果；失效后真的会受到危险接触。不能靠动画看似安全但判定已结束。
- 用真实小屏检查手持武器、脚点、敌人预警与图标的辨认度；不能仅以大图精致作为合格标准。
- 以 60 敌人、连续投射物与多技能组合检查帧率和声音预算；画质降级后保留真实范围、路线、格挡窗口和敌人警示。
- 旧版存档可读，新规则分区记分；测试场景不进入正式纪录。网页先验证闭环，其他平台分别进行真机验收。

这份清单供用户批准后实施与验收，本轮不提前开发其中任何功能。
