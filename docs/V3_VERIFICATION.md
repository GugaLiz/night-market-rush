# V3 清扫玩法开发与验收

日期：2026-11-18。规则版本 `night-market-3.0`。本页覆盖 V2 的寻敌攻击、三行记录和旧难度数值。

## 实装变化

| 反馈 | 当前实现 |
|---|---|
| 人物比小食物大 | 人物按原比例放大至 1.35 倍，约 117 逻辑单位；小包子 55，碗怪 75；玩家顶部活动边界保护人物不被 HUD 遮住 |
| 持续有规律朝前攻击 | 空场也按武器节奏出手；蓄势跟随输入方向、释放后锁定；停下保留最后方向，不自动转向背后敌人 |
| 攻击范围与清扫 | 近战范围 140–180、远程 280–360；不同武器宽幅、散射、穿透、去回、爆炸和跳链仍有区别 |
| 五行爆发伤害 | 每个武器命中总量拆为最多五段真实扣血，死亡立刻停止；同怪最多五行，第六条起折叠；字体 28 缩至 14，独立过期 1.05 秒，死亡显示最多 0.5 秒；全屏最多三十行，玩家槽独立 |
| 打击表现 | 扩大挥击光弧、命中闪星、粒子、短震屏、击败消散、分武器音效；同次五段不叠播五个音效，减少动态设置仍生效 |
| 武器拾取 | 首次约 4 秒，间隔 10–14 秒；最多两自然包加一退换包；光柱、武器实物和文字标识，包间距至少 65 |
| 微加速 | 同向持续 1.8 秒后逐渐加速，最高 1.12 倍；停下、转向或冲刺重置 |
| 主动冲刺 | 按钮 / Space / Shift，沿最后移动方向 0.18 秒，2.5 倍速，冷却 3 秒，期间短暂免伤；独立于摇杆第二手指 |
| 群体敌人 | 包子/盒/碗基础速度 40.5/35.1/24.3；远处游走与缓慢趋近、空间桶软分离；难度容量 45→70→90→100 |
| 特殊敌人 | 箱怪同时最多一个冲刺，预警 1.1 秒；碗怪 30 秒后自然出现，0.9 秒锁方向预警后发射速度 90、伤害 8 的汤弹；同时最多两预警、十二敌弹 |

## 测试与边界

最终完整运行：135 项单元/集成测试通过；TypeScript 与 Vite 正式构建成功。4173 正式产物加载、开始、移动、暂停和声音设置通过，无页面/资源错误，开发调试入口已剔除。

本机短时采样：正式早期对局约 60.5 FPS、p95 16.7 ms；人工百怪多技能场景中位 16.7 ms、p95 33.3 ms（180 帧，自动 DPR 1，期间实际击败敌人）。这是本机 Chromium 数据，尚非低端手机真机结果。

- 核心、武器、技能、伤害布局、存档与机制审查的自动测试通过；包括五段总量守恒、低血量提前死亡、每敌只结算一次击杀、无目标攻击方向、伞挡敌弹、冲刺不耗伞/气泡、同向加速和十分钟实体上限。
- Chromium 浏览器 12 项流程分批通过：原操作回归、十武器真实命中、十三技能、HP与练习场、冲刺键盘冷却、手机双指摇杆加冲刺、暂停与旋转阻止误操作。
- 实际截图检查：人物大小、五行字号收缩、武器弧光、远程预警/汤弹、冲刺、手机按钮以及百怪压力画面。截图与性能数据位于 `docs/verification/v3/`。
- 十分钟纯模拟保持最多一百怪、二十四玩家投射物、十二敌弹。GPU 性能单独测量，不能以逻辑测试速度宣称手机帧率。
- 当前为本地网页，Android、iOS、微信小游戏仍保留适配边界，未新生成平台包。数值按本轮清扫玩法调校，最终体感继续以实际试玩为准。

复验：`npm test`、`npm run test:e2e`、`npm run build`；开发服启动后 `node scripts/verify-v3-visual.mjs`；正式服 `node scripts/verify-production.mjs`。
