# 夜市急送 V2 用户试玩指南

更新日期：2026-11-18。适用于规则版本 `night-market-2.0`。

## 打开与开始

完成构建和本机服务启动后，打开 [本地试玩页](http://localhost:4173)。使用已有部署地址时刷新页面即可加载最新构建。启动、停止和同局域网手机访问步骤见 [部署说明](DEPLOYMENT.md)。

- **开始挑战**：正常生存模式，自然生成敌人、技能道具与可更换武器，生命耗尽后结算。
- **配送试验场**：直接体验 10 款武器和 13 种技能；没有自然刷新，不写入正式最佳纪录。
- **武器与道具图鉴**：查看各武器和技能的用途、数值与限制。

电脑用 WASD 或方向键移动，Esc 暂停；触屏建议横屏拖动摇杆。设置可更改左右手、摇杆大小、音乐与音效音量，以及减少动态和画质。声音在首次点击后解锁。重力感应取决于设备支持与浏览器权限；局域网 HTTP 下优先测试摇杆。

## 当前已经可以体验的内容

玩家默认携带伸缩取餐夹，武器自动选择合法目标并出手；不增加攻击键。拾取地面武器包会换装，已投出的旧武器弹体继续完成。换下来的武器留在地面短暂保留，有退换锁定时间，并需离开再进入拾取区域。

| 武器 | 适合观察的差别 |
| --- | --- |
| 伸缩取餐夹 | 短距离直刺，单目标 20 伤害 |
| 纸袋气炮 | 三方向气流，同次出手对同一怪不重复扣血 |
| 飞筷匣 | 直线贯穿，最多三目标，伤害依次 36 / 28 / 22 |
| 汤灵保温壶 | 追踪汤灵，最多两目标，伤害 32 / 24 |
| 拆箱快刀 | 近身扇面，最多两目标各 24 |
| 回旋餐盘 | 去程 22、回程 18；同一怪可承受两段真实伤害 |
| 折叠配送伞 | 朝向威胁的短防御窗，挡住一次并反击 32；不是持续全向无敌 |
| 签收尺剑 | 较长前摇后的窄直线重击，最多三目标各 52 |
| 弹射餐盒 | 固定落点延迟范围攻击，最多四目标各 44 |
| 派单符册 | 连锁跳向不同敌人，依次 30 / 22 / 16，不重复选同一怪 |

13 种技能包括电扇、滑板、汽水，以及新增的保温盒诱饵、气泡防撞、路锥、手铃、导航路线、取餐钩、加热餐包、派单终端、加急印章和补给券。详细规则见 [技能实现记录](V2_SKILLS_IMPLEMENTATION.md)。正常挑战中按阶段逐步加入道具；试验场可直接选择全部类型。

## 建议按这个顺序试玩

1. **先看移动和默认攻击。** 进入试验场，生成单只包子怪，选择取餐夹并体验。观察站立、起步、停步、横向转身和行走中自动出手。武器必须有合法目标进入范围才会攻击，空地不出手属于正常规则。
2. **比较十款武器。** 点击顶部“试验工具”，选武器后“装备并体验”。选择大碗面怪作为耐打目标，试完一款后可“清空场地”。餐盘观察回程；飞筷、尺剑与符册可用“生成敌群”观察多目标差别。切为 0.5× 速度看前摇与命中时机。
3. **检查生命与接触伤害。** 玩家初始 100 HP。包子接触 8、外卖盒普通接触 12、冲刺接触 20、大碗面接触 18。受伤后有 0.75 秒全局保护，不会因同一时刻重叠多怪瞬间连续扣血。试验场可“补满生命”，正式挑战没有自动回血。
4. **看多行伤害是否清楚。** 用回旋餐盘观察去回两击；用快刀配滑板观察不同来源。每怪只有一条总生命条，伤害记录是最多三行“来源图标＋数字”。第四击折叠早期未过期记录，最新两行保留；记录约 1.2 秒独立到期。致死时显示实际剩余 HP 的扣除量，不显示虚高的过量伤害。
5. **比较逃生技能。** 电扇造成 60 伤害，大碗面可存活；汽水只减速；滑板中心有空隙；气泡只抵消一次；手铃眩晕时贴怪仍可能受伤。控制效果不等于无敌。
6. **观察路线和地面交互。** 放路锥后让外卖盒冲刺撞破；沿导航路线移动感受加速；保温盒最多诱导六只追逐状态敌人，不急停正在冲刺的怪物。再次使用会替换旧区域。
7. **体验补给与拉钩。** 触发补给券，等待 0.35 秒落地，再触发取餐钩；同一补给组最多拉一件，真正拾取后其余收回。补给只能生成基础三种技能；道具满额或无合法落点时至多等待 4 秒。取餐钩不能远程换武器。
8. **最后跑正常挑战。** 体验自然刷怪、武器换装、难度递进和纪录保存。派单终端暂停未来增援，在无自然刷怪的试验场只适合看状态和特效，验证暂停生成应在正常挑战中观察。

试验工具中，“清空场地”用于移除敌人、地面物品、区域和飞行物；已有角色持续状态可能仍在。需要完整对照时使用“重置试验”，保留当前武器并重建本局状态。打开工具或图鉴时，战斗暂停。

## 反馈时重点记录

| 观察项目 | 有帮助的反馈 |
| --- | --- |
| 操作 | 设备与浏览器、摇杆还是键盘，起步/转向/停步是否拖沓 |
| 人物动作 | 哪款武器、移动还是站立，动作与命中是否对得上 |
| 数字与生命条 | 哪只怪、连续几次命中，是否遮脸、遮预警或难分来源 |
| 武器 | 名称、敌人类型、距离、期望结果与实际结果 |
| 音效 | 是否太尖、太吵、没有层次，或听到声音但画面尚未命中 |
| 性能 | 设备、画质、敌人数量的大致情况、是否持续掉帧或发热 |

截图或短录屏可以帮助定位视觉和手感问题。试验场速度应一并说明，0.5× 的出手与移动本来就会变慢。当前伤害记录全屏敌人部分最多 12 行，远处超预算数字可能省略；真实扣血、生命条与战斗统计不受影响。

## 交付与平台边界

本次已实现 Web 游戏规则、武器和技能、生命与伤害反馈、人物动作、原创程序音乐音效、试验场、图鉴、暂停与本地保存。美术采用所选外卖快递员方案；原设计目录中的其他两款主题保留备用，尚无模式切换入口。

Android、iOS 与微信小游戏目前是预留扩展方向：可复用规则核心，但仍需宿主输入、音频、存储与界面适配，以及实际打包和真机验收。当前没有 APK、IPA 或可直接提交的微信工程。手机浏览器可访问网页，不等于原生平台已经完成。

既有设计评审和概念图保留为历史记录，其中旧版“一碰结束”和“尚未开发”的状态不代表当前 V2。当前版本不宣称与原作源码、音效或逐帧手感一致；实际体验以本机运行和后续试玩调整为准。自动化测试能验证规则及显示约束，触控手感、听感和长时间性能仍需实机体验。
