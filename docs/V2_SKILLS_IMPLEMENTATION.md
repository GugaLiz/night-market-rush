# 夜市急送 V2 技能实现

2026-11-18。此页记录已实现的模拟规则；设计评审中的旧版“一击失败”和“待开发”措辞不再代表当前运行版本。视觉、音效和设备验收由整体验收记录单独记录。

## 运行接口

`src/core/skills.ts` 导出 `activateSkill(state, kind, origin, context)` 和 `updateSkills(state, dt, context)`。所有状态保存在 GameState 内，无跨局模块缓存。固定步更新先移动敌人，再更新技能，再收集道具、更新武器和处理玩家接触。技能只发送 `skill` 事件；拾取 `pickup` 事件由 Game 发送，音频消费者应避免同一次拾取播放两次。

## 边界约束

- 地面有效技能道具上限 4，尚未落地的补给已占用名额；撤回动画中的物品不再可拾取或被拉取。
- 补给落点尝试半径 105 的候选点，避开边界、敌人、武器和其他道具。只生成电扇、滑板、汽水，无武器和递归补给。
- 多个手铃延迟事件用独立编号保存在 effects 中，互不覆盖；重开会随 GameState 清除。
- 滑板伤害共用敌人 `skateHitAt`，不会因绘制多个滑板或高刷新率重复扣血。
- 生命伤害事件由 CombatContext.damage 统一产生，技能不虚构伤害数字；实际扣血量与视觉事件一致。

## 自动验证

`npm test -- --run tests/skills.test.ts` 覆盖技能伤害与中空环、每怪伤害节流、扫掠、现有怪物缓速、诱饵上限/到期、状态刷新、路锥冲刺阻挡、手铃延迟/排队/抗性、路线裁切、拉钩分组排他、派单窗口与冷却、补给预留与等待到期。
