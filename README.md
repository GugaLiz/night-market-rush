# <img src="public/icons/delivery-box.svg" width="38" height="38" alt=""> 夜市急送

**[在线试玩《夜市急送》](https://gugaliz.github.io/night-market-rush/)** · 手机请横屏游玩

你是一名跑夜班的外卖员，整条街的小吃都追了上来。武器会自动攻击，你可以冲出包子怪的包围，撞上飘过街面的技能泡，再到亮灯的摊位签收补给或改装配送箱。击败守关精英就能进入下一波，送完尾单后可以收摊，也可以继续跑夜班。

电脑用 WASD 或方向键移动，按空格或 Shift 冲刺。手机拖动摇杆移动，点「冲刺」突围。

## 夜市图鉴

- **武器**　取餐夹挥出两道弧形气浪，纸袋气炮能打出九路散射。用回旋餐盘时，换个位置接盘，就能让餐盘在回程再扫一排怪。
- **技能**　乌金涡锅能把追兵卷到锅心，冰封刨冰机能冻住怪群。装上碎冰箱后，朝带裂纹的怪冲刺，第一只碎开的冰壳会向前射出冰片。
- **怪物**　包子怪会绕到身侧追你，大碗面怪会在远处瞄准。遇到「巨包三连坐」，前两跳躲开落点，第三跳从面粉浪的缺口穿过去。
