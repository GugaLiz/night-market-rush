# 夜市急送

**[在线试玩《夜市急送》](https://gugaliz.github.io/night-market-rush/)**。当前源码中，点「开始挑战」能看到包子怪散在街面各处。可以穿过空隙去取电扇，也可以从几只包子身旁跑过，把追上来的怪带进取餐夹的横扫范围。碗怪能隔着大半条街瞄准，地上的虚线就是汤弹将经过的路线。

取餐夹贴身挥过 226°，夹口带出的双弧金风最远扫到 260 个场地单位，一挥最多打七只。在「配送试验场」换上拆箱快刀、签收尺剑或配送伞，可以试到切风、重压波和伞瓣风。换成纸袋气炮能同时打出九路纸风，三只回旋餐盘则会从不同方向飞回手中。[四款近战气浪](docs/verification/courier/melee.webp) · [六款远程弹道](docs/verification/courier/ranged.webp) · [V4 试玩与参数](docs/V4_PLAYTEST.md)

外卖员的反光头盔、制服斜肩带和背后的热餐标识在转身时可见，保温箱跟着步幅摆动。拾到电扇时，她用空闲手从箱里取扇，风把热餐蒸汽和小票吹向四周。拾到汽水时，瓶口倒下的液流在地面留下三片柠檬水迹。[主角前后对照](docs/verification/courier/character.webp) · [电扇与汽水分镜](docs/verification/courier/skills.webp) · [普通局有声实录](docs/verification/courier/fan/opening.webm)

进「配送试验场」，用默认取餐夹生成单只碗怪。三次挥击后，头顶累计从 54 到 108，再到 120。两次出手之间走开再回来，活怪会从上次总数接着算。击败后总数在原位置停留并淡出，共 2.4 秒。

外卖快递员主题的横屏单人生存游戏。控制人物躲开食物小妖，拾取电扇、滑板和汽水，借助自动触发的技能清理路线并争取更高纪录。当前交付以可运行的 Web 版本为目标，沿用已经选定的暖色手绘夜市风格。

外卖员与包子怪另有三份 Q 版概念图，分别尝试灯影剪纸、软陶盲盒和街机像素，供比较造型与材质。[查看三个美术方向](docs/art-directions/chibi/README.md)

本项目根据已批准的《夜市急送》设计实现原创角色、道具、场景和声音。没有原作源码、逐帧操作测量或原始音效素材，因此不宣称与《宫爆老奶奶》第一部在内容、手感、特效、音效上达到一比一复刻。此处“完整”指当前约定范围内的开始、战斗、暂停、设置、失败结算、重试和本地纪录流程；不代表原作全部内容或四个平台均已完成。

## V4 试玩入口

- **开始挑战**。用 WASD 或方向键移动，反向键一按就掉头，Space 或 Shift 冲刺。横屏触控可一指持续拖动摇杆，另一指点冲刺。持续朝同一方向或沿缓弧移动会逐步提速。已有武器沿行进方向出手，经过地面金币才会收取。正式局首次倒下可免费复活一次或直接结算。
- **配送试验场 → 取卡清场**。朝右走到电扇，看蒸汽从近处先起、五股带着小票的气流依次出现在外围，再穿过掉币区域收取金币。重新打开工具可重置样例。
- **配送试验场 → 连续换波**。看住右方的一件道具和一簇金币，约两秒后夜市切换到河畔茶市，再移动收取。试验场独立于本地最佳纪录。

V4 沿用十款武器、十三种技能、100 点生命和已有操作偏好。成绩按击败数记录，金币和时间分列。本次开局调校沿用 V4 的纪录。两张夜市背景交替出现，波次可继续超过第七波。

## V3 历史版本：主动清扫、五段打击与冲刺

人物放大 35%，武器持续朝行进方向挥击或发射，停止移动时保持最后方向。十款武器扩大攻击范围并支持群体命中；每次武器伤害按总额拆成最多五段真实扣血，敌人死亡立即停止结算。每怪最多五行伤害数字，字号由大变小后消失，第六条起折叠旧记录，全屏最多三十行并避让。

持续同向移动逐步增加最多 12% 速度；点击冲刺按钮或按 Space / Shift 可沿最后方向冲刺，冷却三秒。普通怪移动减慢、在远处游走并相互分散，场地容量逐步提高至一百只。碗怪增加提前 0.9 秒锁定方向的慢弹，同时最多两只预警；箱怪冲刺变慢、预警延长且同时最多一只。

局内首次武器包约四秒出现，此后约十至十四秒补充；最多两个自然武器包与一个退换包，光柱和名称标识可见。详细操作与验证见 [V3 试玩指南](docs/V3_PLAYTEST.md) 与 [V3 核心说明](docs/V3_CORE_IMPLEMENTATION.md)。

## V2 历史版本：武器、生命与多段反馈

V2 已实现默认武器与自动攻击、10 款可换装武器、13 种技能道具、100 点玩家生命、不同怪物的接触伤害、敌人生命条，以及每怪最多三行的真实伤害记录。连续第四击会折叠较早命中，最新两击仍独立显示；每次记录独立到期，玩家受伤与回血单独显示。人物增加站立、移动、战斗和受击表现，声音使用原创程序合成。

从首页进入 **配送试验场**，可直接换武器、触发技能、生成单只或敌群、补满生命、清空场地，以及用 0.5× 速度观察多段攻击。打开试验工具时暂停模拟，试验结果不写入正式最佳纪录。首页的 **武器与道具图鉴** 可查看全部机制。详细试法见 [V2 用户试玩指南](docs/V2_PLAYTEST.md)，技能实现数值见 [V2 技能实现记录](docs/V2_SKILLS_IMPLEMENTATION.md)。

V2 引入生命、自动攻击、换装与十三种技能。下方的 V1 玩法记录仅供版本追溯。

当前可运行交付仍是 **Web 网页**。Android、iOS 和微信小游戏保留规则核心与宿主接口的复用边界，尚未生成原生安装包或可提交的微信工程，也尚未完成对应平台真机验收。浏览器运行、响应式横屏适配和试验场可用，不代表四个平台均已发布。

## 运行网页版

在项目根目录使用 Node.js 22.12 或更新的兼容版本。Windows PowerShell 使用 `npm.cmd`：

```powershell
npm.cmd ci
npm.cmd test
node --test scripts/server-test.mjs
npm.cmd run build
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/start-web.ps1
```

构建和启动成功后访问 [http://localhost:4173](http://localhost:4173)。启动脚本隐藏运行窗口，重复启动会复用已验证的健康进程。手机可使用同一局域网电脑的 IPv4 地址访问，实际连通取决于网络和防火墙；手机局域网 HTTP 通常不具备完整的设备运动权限条件，测试重力感应应使用 HTTPS。

停止本项目后台服务：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/stop-web.ps1
```

开发时使用 `npm.cmd run dev`，默认端口 5173；前台运行构建产物使用 `npm.cmd run serve`，默认端口 4173。改动源文件后需要重新构建，再刷新部署页面。详见 [部署文档](docs/DEPLOYMENT.md)。

## V1 历史操作与玩法

| 操作 | 用法 |
|---|---|
| 电脑 | WASD 或方向键移动，Esc 暂停；也可在操作半屏按住鼠标拖动摇杆 |
| 触屏 | 横屏，在所选操作半屏按住并拖动浮动摇杆；设置中可改左右手和摇杆大小 |
| 倾斜 | 设置中选择重力感应，允许设备权限并校准舒适姿态；无有效传感器数据时使用摇杆 |
| 技能 | 走到道具上立即触发，没有攻击键、手动施法键或普通自动射击 |

包子怪持续追踪，外卖盒怪预警后沿锁定方向冲刺，大碗面怪以较大体积缓慢逼近。碰到仍有威胁的怪物即结束本局。生存每满一秒获得 10 分，击败敌人另计分。

电扇瞬时范围清怪；滑板持续环绕攻击 4 秒，中心空隙仍然危险；汽水对拾取瞬间范围内的敌人减速 3 秒，不造成伤害。四个连续生存阶段在 30、90、180 秒进入下一阶段，后期生成频率和敌人数有上限。

## V1 历史交付范围

- 一个夜市场景、一名快递员、三类敌人、三类道具和四阶段难度。人物目前采用两帧跑步精灵；不是完整多方向逐帧动画库。
- 战斗 HUD、暂停、操作/声音/画面设置、教程、结算与重试；本地保存设置和最佳纪录。
- 原创 Web Audio 程序音乐与音效，提供音乐/音效独立音量及静音；声音需要首次用户操作解锁。
- TypeScript 规则核心、Canvas 2D 战场、HTML/CSS 界面、Vite 构建。旧策划中的 Cocos 是候选路线，本次实际采用 Web 架构。
- Android/iOS 容器与微信小游戏保留接入边界，尚未完成原生安装包、微信工程、商店发布或真机验收。微信小游戏需要替换 DOM UI 和平台服务，不能直接把网页构建作为小游戏提交。

《月影图书馆》《珊瑚救援队》为备用主题。主题与平台范围见仓库内的[已确认需求](docs/问题清单/已确认需求与待核实问题.md)。

## 目录

```text
night-market-rush/
  src/core/          纯游戏规则、难度配置、连续碰撞
  src/platform/      浏览器输入、程序音频、存档与宿主契约
  src/shared/        实体、设置、事件及规则版本类型
  src/ui/            游戏界面、HUD、设置与样式
  src/main.ts        Web 应用入口、状态流程与固定步长调度
  public/assets/     夜市场景和人物/怪物/道具图集
  tests/             规则、模拟集成与存档测试
  scripts/           静态服务、后台启动/停止和服务测试
  docs/              实现、资产、平台和部署文档
  dist/              构建产物，执行 build 后生成
```

场景渲染由 `src/render` 接入 Canvas，应用入口连接上述模块，平台扩展优先复用 `src/core` 与 `src/shared`。目录中 `.runtime/` 和 `.night-market-server.json` 为运行记录，不是源代码。

## 验证与限制

`npm.cmd test` 检查同帧拾取与失败顺序、连续碰撞、技能环空隙、冲刺预警、生成与难度上限、固定步长/种子重放，以及损坏存档和跨标签纪录保护。静态服务器有独立的路径安全、MIME、缓存和健康检查测试。`npm.cmd run build` 包含 TypeScript 类型检查。测试明细与设备验收要求见 [实现说明](docs/IMPLEMENTATION.md)。

自动化通过不能证明手机上的触控手感、音画延迟和持续帧率已经合格；这几项仍须用户实际试玩和真机验证。当前音乐为程序合成，图集动画有限，字体使用设备可用字体回退。跨设备本地纪录不会自动同步。
